# Регрессионный набор CHERNENKO SITES — roast-coffee

Статус: базовая версия до утверждения редизайна. Код сайта в ветке main не изменён.

8 товаров, фильтры all/light/medium/dark/decaf, поиск, сортировка. localStorage корзины и лимит 99 единиц. Доставка 350 ₽ до 3500 ₽, дальше бесплатна. Оплата и отправка отсутствуют.

## Выполнение

1. Установить Node.js 20+.
2. В корне репозитория: `npm --prefix qa install`.
3. Установить Chromium: `npx --prefix qa playwright install chromium`.
4. Запустить тесты: `npm --prefix qa test`.

Playwright поднимает локальный HTTP-сервер на 127.0.0.1:4173; тесты НЕ отправляют заявки, не берут платежи, не используют реальных клиентов.

Тестовые снимки сохраняются в `qa/artifacts` при запуске тестов; это скриншоты **базовой версии**, не утверждённого нового дизайна. Форматы: 360, 768, 1280, 1440 px, fullPage.

## Критерии выхода

- Все автотесты проходят, отсутствует горизонтальная прокрутка на контрольных ширинах.
- Клавиатурные сценарии и фокус не ломаются.
- Все суммы соответствуют тарифам; некорректный контакт или параметры отклоняются.
- Подготовленный заказ или запись явно описаны как демонстрационные.
- Новый дизайн и изменение main только после директорского утверждения.

⚠️ Наличие тестового кода не означает, что тесты уже выполнены. Результат определяется отчётом Playwright при запуске.
